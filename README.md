## Usage
Download the installer script and then execute it with `bash` as root. Running the
script from a file ensures that its interactive prompts work correctly.

```bash
curl -sSL -o auto_install.sh \
  https://raw.githubusercontent.com/HyHamza/SERVER-CONFIG/refs/heads/main/auto_install.sh
sudo bash auto_install.sh
```

The script requires root privileges and will download the necessary installer components.
